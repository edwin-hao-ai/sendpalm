设计要点

关窗 ≠ 退出。macOS 上红色关闭按钮默认隐藏窗口（应用仍在 Dock）；真正的退出只在托盘菜单 / ⌘Q。Windows 同理（X → 托盘）。
托盘 = 状态 + 入口，不是第二个 App。菜单只放：最新几封邮件（点击直接打开对应会话）、写邮件、Gate 待办、连接状态、设置、退出。
Agent 网关在后台保持可用——这正是你提到的痛点：托盘活着，OpenCode / Claude Code 随时能读写邮件，不需要主窗口开着。
未读徽标实时显示在托盘图标上；数字为 0 时徽标消失，菜单切换为简洁态。
