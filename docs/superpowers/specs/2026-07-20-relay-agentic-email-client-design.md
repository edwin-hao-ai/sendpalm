> 范围：桌面端（Tauri）邮件客户端的 HTML prototype 阶段

## 1. 产品定位

一句话定位：

> **以人为中心的 Agentic 邮件客户端**：默认界面不是文件夹，而是「你和谁、最近聊了什么、AI 觉得你该做什么」的时间线。同时，它能把任何联系人、邮件线程、会议自动导出成 Markdown 上下文文档，供 Claude / Codex / Cursor 等外部 AI 代理继续处理。

### 1.1 范围（本阶段）

| 包含 | 不包含（后续阶段） |
|---|---|
| 邮件：Gmail / Outlook / IMAP | Slack / 微信 / WhatsApp / LinkedIn |
| 日历集成（会前准备、会后纪要） | 团队共享关系图谱 |
| 联系人、公司、邮件线程、会议、文件 | 企业版 SSO / 私有部署 |
| AI 分类、摘要、起草、跟进提醒 | 移动端 Companion App |
| Markdown 上下文导出 | MCP server / JSON API（可扩展） |

### 1.2 核心设计原则

1. **人 > 邮件**：所有邮件都归到「联系人」或「公司」下，不存在孤立的邮件列表。
2. **时间线即主页**：打开应用看到的是一个 Feed，而不是收件箱文件夹。
3. **Agent 不抢戏**：Agent 以「行动卡片」和右下角悬浮按钮的形式出现，平时不打扰。
4. **上下文可导出**：每个联系人、每封邮件线程、每个会议都能一键生成 Markdown。
5. **不要 CRM 感**：联系人详情服务于沟通，而不是销售漏斗。

## 2. 信息架构与布局

### 2.1 整体结构

```
┌─────────────────────────────────────────────────────────────┐
│  顶部全局栏：搜索 / 当前视图标题 / 通知 / 主题切换              │
├──────────┬──────────────────────────────────────────────────┤
│          │                                                   │
│  左侧深色 │   中间主内容区（浅色）                             │
│  导航栏  │                                                   │
│          │   默认视图 = 「For You 时间线」                    │
│  · For You│   - 按人聚合的通信卡片流                           │
│  · People │   - 内嵌 AI 待确认回复卡片                         │
│  · Cal    │   - 智能分类标签：Needs Reply / Follow Up / News  │
│  · Files  │                                                   │
│  · Drafts │   选中联系人/邮件后 → 右侧滑出详情层               │
│          │                                                   │
├──────────┴──────────────────────────────────────────────────┤
│  右下角：Agent 悬浮按钮（可展开为聊天面板）                    │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 左侧导航（深色侧边栏）

- **For You**（默认）
- **People**（联系人目录，支持按活跃度 / 需跟进 / 冷淡筛选）
- **Calendar**（会议 + 会前准备状态）
- **Files**（按人索引的附件）
- **Drafts**（AI 待确认草稿 + 手动草稿）
- 底部：**Settings / 账户**

### 2.3 中间主内容区

顶部分段标签：

```
All · Needs Reply · Follow Up · News · Done
```

默认 Feed 按时间倒序，但 `Needs Reply` 和 `Follow Up` 的卡片会轻微置顶/高亮。

每条卡片包含：
- 头像
- 联系人姓名
- 公司/职位
- 主题一行摘要
- 时间
- 渠道图标（邮件 / 日历）
- 未读/待处理标记

### 2.4 右侧详情层

- 选中**联系人** → 滑出联系人面板（Xobni 式：邮件历史、文件、洞察、关系网络、日历）
- 选中**邮件** → 展开邮件阅读视图 + 快捷回复区
- 选中**会议** → 会议准备包 + 参会人关系

### 2.5 Agent

- 右下角圆形头像按钮，有新建议时 pulse
- 点击展开右侧/底部聊天面板，可输入自然语言命令

## 3. 视觉与材质方向

### 3.1 Design Read

这是一款面向高沟通强度专业人士（投行/咨询/销售/创始人）的桌面 AI 邮件客户端，需要让人感觉像原生 Mac 应用，既有秩序感又有智能感。

**Reading this as**: dense productivity app for communication-heavy professionals, with a premium-consumer finish, leaning toward Apple-native clarity + restrained glassmorphism.

### 3.2 三旋钮

| 旋钮 | 值 | 理由 |
|---|---|---|
| DESIGN_VARIANCE | 5 | 产品 UI 以对称网格为主，卡片内部和 Agent 面板可轻微不对称 |
| MOTION_INTENSITY | 4 | 以状态过渡和微反馈为主，不做 landing page 式 scroll 动画 |
| VISUAL_DENSITY | 6 | 信息密度中高，但用留白和层级避免拥挤 |

### 3.3 颜色

| Token | 值 | 用途 |
|---|---|---|
| 导航/Agent 背景 | `#08090d` | 左侧栏、右侧 Agent 面板 |
| 主内容背景 | `#f8f8f6` | 温暖米白，避免冷白刺眼 |
| 强调色 | `#5B4CDB` | 选中态、Agent 按钮、链接、聚焦描边 |
| 成功 | `#10b981` | 已发送、健康度高 |
| 警告 | `#f59e0b` | 临近截止、健康度下降 |
| 紧急 | `#ef4444` | 超期未回复、错误 |
| 卡片边框 | `rgba(0,0,0,0.04)` | 1px 细线 |

**禁用**：AI 紫渐变、霓虹 glow、纯黑/纯白背景。

### 3.4 字体

| 角色 | 字体 |
|---|---|
| UI 正文 | Geist Sans |
| 数据/标签/时间 | Geist Mono |
| 大标题 | Geist Sans（不在密集 UI 里额外用 Clash Display） |

行高：正文 1.5，标题 1.2。

### 3.5 材质与层次

- **左侧/Agent**：实心深色，不用毛玻璃，避免过度装饰。
- **主内容区卡片**：极浅阴影 + 1px 边框，hover 时轻微上浮。
- **悬浮 Agent 按钮**：毛玻璃胶囊，带 1px 白色内边反光，拉开与普通按钮的层次。
- **搜索框/输入框**：浅灰底，聚焦时 2px 品牌色描边。

### 3.6 反庸俗校准

- 不用三列等宽功能卡
- 不用 Inter 作主字体
- 不用紫色渐变背景
- 不用假截图 / div 拼的产品预览
- 每个动画都有目的：hover 反馈、面板展开、新消息进入

## 4. 关键视图与交互

### 4.1 For You 时间线（默认主页）

打开应用看到的第一屏。它是一个按时间倒序排列的「通信事件流」：

| 卡片类型 | 内容 |
|---|---|
| 普通邮件 | 头像、发件人、公司/职位、主题摘要、时间、渠道图标 |
| 会议事件 | 日历图标、标题、参会人头像组、距开始时间、「生成简报」按钮 |
| AI 待确认回复 | 替换原本需要回复的邮件位置，显示 AI 回复预览，底部 `Send · Edit · Ignore` |
| 关系提醒 | 「你和张磊 12 天没联系了」，附带一键「起草问候」 |

**交互**：
- 点击卡片 → 右侧滑出详情层
- 长按/右键 → 标记为「需跟进 / 已完成 / 忽略」
- 顶部标签切换：`All · Needs Reply · Follow Up · News · Done`

### 4.2 People 视图

左侧联系人目录，右侧选中联系人详情：

- 联系人列表支持：按活跃度 / 需跟进 / 冷淡筛选；按人 / 按公司分组
- 联系人卡片显示：头像、姓名、公司、最近联系时间、健康度分数、未读数
- 详情面板标签页：
  - **Timeline**：邮件 + 会议 混合时间线
  - **Files**：此人相关附件
  - **Insights**：回复时间趋势、常见话题、沟通模式
  - **Network**：共同联系人、同事、相似联系人
  - **Calendar**：与此人的会议

### 4.3 邮件阅读视图

选中邮件后右侧展开：

- 顶部：发件人信息、收件人、时间、标签/分类
- 主体：干净的阅读区，支持折叠引用
- 底部快捷操作：`Reply · Reply All · Forward · 交给 Agent · 标记跟进`
- 快捷回复区：点击 Reply 后底部出现输入框，Agent 自动预填建议回复

### 4.4 Calendar 视图

- 会议列表 + 时间线
- 每个会议显示：参会人、关系健康度、简报状态
- 会前自动生成准备包（相关邮件 + 文件 + 上次纪要）
- 会后支持生成纪要 + action items

### 4.5 Agent 面板

右下角悬浮按钮点击后展开：

- 当前上下文提示：「正在看：张磊的邮件」
- 建议操作卡片：总结、起草回复、安排会议、提取待办
- 自然语言输入框
- 进行中的任务列表（步骤级进度）

## 5. Agent 上下文输出

### 5.1 可导出对象

- 联系人（Person）
- 邮件线程（Thread）
- 单个会议（Meeting）
- 项目/话题（Topic）
- 当前待办/跟进列表

### 5.2 导出形式

- **默认格式**：Markdown
- **本地路径**：`~/.relay/context/{date}/{type}_{id}.md`
- **界面入口**：联系人面板、邮件详情、会议卡片右上角的 `Copy context` 按钮

点击后：
1. 生成 Markdown 并复制到剪贴板
2. 同时保存到本地 context 目录
3. 显示短暂 toast：`Context copied for Claude`

### 5.3 Markdown 示例（联系人）

```markdown
# 张磊 (Zhanglei Zhang)

## 基本信息
- 公司: 华为技术有限公司
- 职位: 战略合作总监
- 邮箱: zhanglei@huawei.com
- 健康度: 72/100 (下降趋势)

## 最近沟通
- 2026-07-18: 邮件 — "Q4 合同付款条款确认"
- 2026-07-15: 会议 — "Q4 合同启动会"

## 待跟进事项
- [ ] 确认付款条款修改 (截止 2026-07-22)

## 常见话题
Q4 合同、付款条款、交付物

## 关系网络
- 共同联系人: 陈欣
- 同事: 李强、王洋
```

### 5.4 后续扩展

- JSON 版本
- MCP server，让 Claude Code 直接查询
- 自动把当前选中的上下文附加到 Agent 面板对话

## 6. 设计决策记录

### 6.1 放弃 CRM 感

虽然 Xobni 和 FEATURES.md 里有很多 CRM 式功能（公司聚合、关系阶段、健康度），但本阶段设计把它们放在联系人详情的标签页里，而不是默认视图，避免产品变成销售工具。

### 6.2 双栏 + 浮动 Agent

选择了双栏布局而不是三栏，因为：
- 三栏会让内容区过窄，阅读邮件体验差
- 右侧详情层按需滑出，既保留上下文，又不常驻占用空间
- 浮动 Agent 比常驻侧边栏更轻量

### 6.3 浅色内容区 + 深色导航

用户明确选择。原因是：
- 长时间阅读邮件，浅色背景更舒适
- 深色导航提供清晰边界，让主内容区更突出
- 比全深色方案更像原生邮件应用

### 6.4 待确认草稿内嵌在 Feed

用户明确选择。AI 起草的回复直接出现在原本需要回复的邮件位置，减少上下文切换，符合「一键确认发送」的核心体验。

## 7. 非目标（本阶段明确不做）

- 多端实时同步
- 团队协作 / 共享关系图谱
- 复杂工作流委托（如「帮我 handle 华为项目所有会议安排」）
- 移动版 UI
- 邮件发送的真实后端（prototype 阶段只做 UI 和模拟数据）
- 本地向量数据库 / 本地 LLM 的完整实现（prototype 阶段用模拟数据）
